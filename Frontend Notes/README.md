## 🚀 Module Overview

- **01-Internet-Fundamentals**: Computer networks, IP addresses, DNS lookup, HTTP request/response structure, browser rendering engine pipelines.
- **02-HTML-CSS**: HTML5 semantic markup, forms, accessibility, CSS box model, flexbox 1D layouts, grid 2D layouts, responsive design using `clamp()` and media queries.
- **03_JavaScript**: JavaScript handbooks (`JS_Hand_Book.md` & `Advance_JavaScript/JS_Advance_Hand_Book.md`) covering Modules 1–20 (Syntax, Functions, Closures, Async/Promises, Event Loop, Prototypes, V8 Engine, Memory Optimization, Design Patterns, and Web APIs) alongside topic guides.
- **04-Git-And-GitHub**: Version control fundamentals, branching strategies, merge conflict resolution, pull request workflows, cheat sheet.
- **05-ReactJS**: Component architecture, JSX, props, state management, Hooks (`useState`, `useEffect`, `useContext`, `useReducer`, `useMemo`, `useCallback`), React Router v6, virtual DOM diffing & performance optimizations.
