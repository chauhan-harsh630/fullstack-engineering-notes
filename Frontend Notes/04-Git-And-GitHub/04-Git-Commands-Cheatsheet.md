# 📋 Essential Git Commands Cheat Sheet

## 📖 Overview

A reference cheat sheet for standard day-to-day Git CLI operations.

---

## 🛠 Command Reference

| Command | Action |
| ------- | ------ |
| `git init` | Initialize new local repository |
| `git clone <url>` | Download remote repository locally |
| `git status` | Check status of modified / staged files |
| `git add .` | Stage all modified files |
| `git commit -m "msg"` | Save staged snapshot with a commit message |
| `git push origin <branch>` | Upload local commits to remote GitHub repository |
| `git pull origin <branch>` | Fetch and merge latest remote changes |
| `git log --oneline` | View simplified history commit log |
| `git stash` | Temporarily stash uncommitted working changes |
| `git stash pop` | Re-apply stashed changes |

---

## 📌 Summary
* Use `git status` constantly to inspect working tree state.
