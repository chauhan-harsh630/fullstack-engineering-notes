# 🐙 GitHub Feature Branch Workflow & Pull Requests

## 📖 Overview

The **GitHub Feature Branch Workflow** is the standard industry process for team collaboration and code reviews.

---

## 🔄 Feature Branch Workflow Steps

```text
1. Clone Remote Repo:     git clone <url>
2. Create Feature Branch:  git checkout -b feature/search
3. Commit Changes:        git add . && git commit -m "Add search feature"
4. Push to GitHub:        git push origin feature/search
5. Open Pull Request:     Submit PR on GitHub UI for team review
6. Code Review & Merge:   Teammates review code, CI passes, merge to main
```

---

## 📌 Summary
* Submit Pull Requests (PRs) for code reviews before merging code into production `main`.
