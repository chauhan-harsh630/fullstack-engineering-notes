# 🔒 HTTP vs HTTPS & Security

## 📖 Overview

* **HTTP (HyperText Transfer Protocol)**: Transfers data in plain text over TCP port 80.
* **HTTPS (HTTP Secure)**: Encrypts data transfers over TCP port 443 using **TLS/SSL (Transport Layer Security)**.

---

## 🔒 Why HTTPS is Mandatory
1. **Confidentiality**: Encrypts requests so eavesdroppers (e.g., public Wi-Fi sniffers) cannot read passwords, cookies, or credit card info.
2. **Integrity**: Prevents man-in-the-middle (MITM) attackers from modifying web pages during transmission.
3. **Authentication**: Uses Digital Certificates signed by trusted Certificate Authorities (CAs) to verify website identity.

---

## 📌 Summary
* HTTPS encrypts HTTP traffic using TLS/SSL over port 443.
