# 🧱 HTML Fundamentals & Document Structure

## 📖 Overview

**HTML (HyperText Markup Language)** is the standard markup language used to structure web documents.

---

## 🛠 HTML5 Skeleton

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Document Title</title>
</head>
<body>
  <h1>Welcome to HTML5</h1>
  <p>Standard document structure.</p>
</body>
</html>
```

---

## ⚡ Block vs Inline Elements

* **Block Elements** (e.g., `<div>`, `<p>`, `<h1>`, `<section>`): Start on a new line and take up full available container width.
* **Inline Elements** (e.g., `<span>`, `<a>`, `<img>`, `<strong>`): Do not start on a new line; take up only necessary content width.

---

## 📌 Summary
* HTML defines web document structure using tags, elements, and attributes.
