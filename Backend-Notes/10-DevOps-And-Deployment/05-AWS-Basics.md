# ☁️ AWS Cloud Fundamentals

## 📖 Overview

**Amazon Web Services (AWS)** is the industry-leading cloud provider. Understanding its core infrastructure building blocks is crucial for backend architecture.

---

## 🛠 Essential AWS Services

* **EC2 (Elastic Compute Cloud)**: Virtual private servers in the cloud.
* **S3 (Simple Storage Service)**: Object storage bucket system for images, user uploads, videos, and backups.
* **RDS (Relational Database Service)**: Managed PostgreSQL / MySQL instances handling automated multi-region backups, failover, and hardware scaling.
* **Lambda**: Serverless computing service running code on-demand in response to events without provisioning servers.
* **ECS / EKS**: Container management services (Elastic Container Service / Kubernetes).
* **CloudFront**: Global Content Delivery Network (CDN) caching static assets near users.

---

## 📌 Summary
* AWS provides cloud primitives: EC2 for compute, S3 for media storage, RDS for database management, and CloudFront for CDN distribution.
